# Harness Coding

Enterprise AI coding orchestration system.

7 roles, 10-step workflow, 4-layer gates, experience loop.

## Architecture

```
人类需求层 → 工程契约层 → 代码执行层 → 经验沉淀循环
```

## Quick Start

```bash
# Initialize harness in your project
harness init

# Start a new task
harness start "requirement description"
```
